计算机组成原理 · 课程要点（示例语料）
=====================================

第 3 章 存储系统
----------------
Cache 与主存的映射方式有三种：直接映射、全相联映射、组相联映射。
直接映射的地址结构为：标记（Tag）+ 行号（Index）+ 块内偏移（Offset）。优点是硬件简单、命中判断快；缺点是冲突缺失率高，因为一个主存块只能放到唯一一个 Cache 行。
全相联映射允许任意主存块放入任意 Cache 行，冲突缺失最少，但需要并行比较所有行的标记，硬件成本最高，只适合小容量 Cache。
组相联映射是两者的折中：先按组号定位到某一组，再在组内全相联查找。组相联度 k 表示每组有 k 行，常见的有 2 路、4 路、8 路组相联。

Cache 写策略分为写直达（Write Through）和写回（Write Back）。
写直达：每次写操作同时写 Cache 和主存，实现简单，但总线流量大，通常配合写缓冲（Write Buffer）使用。
写回：只写 Cache，并置脏位（Dirty Bit），仅当该行被替换时才写回主存。总线流量小，但需要额外的脏位和控制逻辑，且多核环境下需要处理缓存一致性。

替换算法常见的有 FIFO、LRU、LFU 和随机替换。LRU（最近最少使用）命中率较高，但需要为每行维护访问计数或使用栈式结构，硬件开销大。

第 4 章 指令系统
----------------
指令的寻址方式包括：立即寻址、直接寻址、间接寻址、寄存器寻址、寄存器间接寻址、基址寻址、变址寻址、相对寻址。
相对寻址的有效地址 = PC 当前值 + 位移量，常用于转移指令，便于程序浮动（位置无关代码）。
变址寻址的有效地址 = 变址寄存器内容 + 形式地址，适合处理数组和循环。

CISC 与 RISC 的区别：
CISC 指令数量多、格式复杂、变长编码、寻址方式丰富，一条指令可完成较复杂的功能，控制器多用微程序实现。
RISC 指令数量少、格式规整、定长编码、寻址方式简单，通常采用 load/store 结构，只有取数和存数指令访问存储器，控制器多用硬布线实现，便于流水线。

第 5 章 中央处理器
------------------
指令流水线把一条指令的执行划分为若干阶段，典型五段流水线为：取指（IF）、译码（ID）、执行（EX）、访存（MEM）、写回（WB）。
理想情况下，流水线每个时钟周期完成一条指令，加速比接近流水段数 k，但受三类相关影响：

1. 结构相关（资源相关）：多条指令在同一周期争用同一硬件资源，例如同时访问存储器。解决方法是增加资源（指令 Cache 与数据 Cache 分离）或停顿。
2. 数据相关：后一条指令需要前一条指令尚未产生的结果。分为 RAW（写后读）、WAR（读后写）、WAW（写后写），其中 RAW 最常见。解决方法有：插入气泡（stall）、数据前推（forwarding/bypassing）、编译器指令重排。
3. 控制相关：由转移指令引起，转移结果未确定时流水线不知道该取哪条指令。解决方法有：延迟转移（delayed branch）、分支预测（静态预测或动态预测如两位饱和计数器）、以及转移目标缓冲器 BTB。

流水线的性能指标：
吞吐率 TP = 指令条数 / 流水线总时间。
加速比 S = 不使用流水线的时间 / 使用流水线的时间。
效率 E = 加速比 / 流水段数。
考虑流水段数 k、指令条数 n、每段耗时 Δt，则总时间 T = (k + n - 1) × Δt，加速比 S = n·k·Δt / T = n·k / (k + n - 1)。

超标量（Superscalar）：一个时钟周期内发射多条指令，需要多条流水线并行。
超流水线（Superpipelining）：把流水段进一步细分，提高时钟频率。
超长指令字（VLIW）：由编译器把多个可并行操作打包成一条长指令，硬件不做调度。

第 6 章 总线与 I/O
------------------
总线按功能分为数据总线、地址总线和控制总线。
总线带宽 = 总线宽度（字节） × 总线频率。例如 32 位宽、100 MHz 的总线，带宽 = 4 B × 100 M = 400 MB/s。

I/O 控制方式有三种：程序查询方式（CPU 忙等，效率最低）、中断方式（外设就绪时发中断，CPU 响应后传送数据）、DMA 方式（由 DMA 控制器直接在主存与外设之间传送数据块，仅在传送开始和结束时打扰 CPU，适合磁盘等高速块设备）。

程序中断方式中，中断响应过程包括：关中断、保存断点、识别中断源、转中断服务程序；中断返回时需要恢复现场并开中断。
中断屏蔽字可以改变中断处理优先级，实现多重中断（中断嵌套）。

第 2 章 数据表示
----------------
定点数补码表示：正数的补码与原码相同；负数的补码为其原码除符号位外各位取反再加 1。
补码的优点是零的表示唯一，且减法可以统一为加法实现。

IEEE 754 单精度浮点数共 32 位：1 位符号位 S、8 位阶码 E（移码表示，偏置值 127）、23 位尾数 M（隐含最高位 1）。
真值计算公式：(-1)^S × 1.M × 2^(E-127)。
双精度为 64 位：1 位符号、11 位阶码（偏置 1023）、52 位尾数。
特殊值：阶码全 0 且尾数为 0 表示 ±0；阶码全 1 且尾数为 0 表示 ±∞；阶码全 1 且尾数非 0 表示 NaN。

浮点数加减运算步骤：对阶（小阶向大阶看齐）、尾数求和、规格化（左规或右规）、舍入（0 舍 1 入、恒置 1 等）、溢出判断。
